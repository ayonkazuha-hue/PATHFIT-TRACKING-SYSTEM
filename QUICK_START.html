After installing XAMPP: Copy all files to C:\xampp\htdocs\pathfit\ and start Apache from XAMPP Control Panel.
2

Setup Supabase Database

Supabase is a free PostgreSQL database service. No credit card required.

  • Go to supabase.com and create a free account
  • Click "New Project" and wait 2-3 minutes for initialization
  • Go to SQL Editor → New Query
  • Open schema.sql from this folder and copy ALL contents
  • Paste into Supabase and click "Run"
  • Go to Project Settings → API and copy your credentials

3

Configure config.php

Open config.php in Notepad and replace the placeholder values:

define('SUPABASE_URL', 'https://YOUR_PROJECT_ID.supabase.co'); define('SUPABASE_ANON_KEY', 'YOUR_ANON_KEY_HERE'); define('SUPABASE_SERVICE_KEY', 'YOUR_SERVICE_ROLE_KEY_HERE');

Paste your actual Supabase credentials from Step 2 and save the file.

4

Start the Server

Choose based on what you installed in Step 1:

XAMPP

Open XAMPP Control Panel → Start Apache

http://localhost/pathfit/login.php

PHP Built-in

Double-click START_SERVER.bat in this folder

http://localhost:8000/login.php

Laragon

Start Laragon → Right-click tray icon → www → pathfit

http://pathfit.test/login.php
5

Verify Setup

Before logging in, run the setup checker to verify everything is configured correctly:

Run Setup Checker or Go Directly to Login
6

Create First Instructor

Since there are no users yet, you need to create an instructor account:

  • Click "Register here" on the login page
  • Fill in all required fields (use any student ID like INST-001)
  • After registration, go to Supabase Dashboard → Table Editor → users
  • Find your user and change role from "student" to "instructor"
  • Log in again — you'll now see the Instructor Dashboard!
Important: Students can self-register normally. Only the first instructor needs manual role change.
