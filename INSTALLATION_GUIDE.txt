STEP 1: INSTALL PHP SERVER
═══════════════════════════════════════════════════════════════════════════════

Choose ONE option:

┌─ OPTION A: XAMPP (Easiest for beginners) ─────────────────────────────────┐
│                                                                             │
│  1. Download XAMPP from: https://www.apachefriends.org/download.html       │
│  2. Run installer (choose default options)                                 │
│  3. Install to: C:\xampp                                                    │
│  4. Open XAMPP Control Panel                                               │
│  5. Click "Start" next to Apache                                           │
│  6. Copy all PHP files to: C:\xampp\htdocs\pathfit\                        │
│  7. Open browser: http://localhost/pathfit/login.php                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ OPTION B: PHP Built-in Server (Lightweight) ─────────────────────────────┐
│                                                                             │
│  1. Download PHP 8.x from: https://windows.php.net/download/               │
│  2. Choose "Thread Safe" ZIP file                                          │
│  3. Extract to: C:\php                                                      │
│  4. Add C:\php to Windows PATH:                                            │
│     - Search "Environment Variables" in Windows                            │
│     - Edit "Path" variable                                                 │
│     - Add new entry: C:\php                                                │
│  5. Restart Command Prompt                                                 │
│  6. Double-click START_SERVER.bat in this folder                           │
│  7. Open browser: http://localhost:8000/login.php                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ OPTION C: Laragon (Modern, all-in-one) ──────────────────────────────────┐
│                                                                             │
│  1. Download Laragon from: https://laragon.org/download/                   │
│  2. Install (choose "Full" version)                                        │
│  3. Copy this folder to: C:\laragon\www\pathfit\                           │
│  4. Start Laragon                                                          │
│  5. Right-click Laragon tray icon → www → pathfit                          │
│  6. Browser opens automatically                                            │
│                                                                             │

STEP 3: CONFIGURE config.php
═══════════════════════════════════════════════════════════════════════════════

1. Open config.php in Notepad or any text editor
2. Find these three lines at the top:

   define('SUPABASE_URL', 'https://YOUR_PROJECT_ID.supabase.co');
   define('SUPABASE_ANON_KEY', 'YOUR_ANON_KEY_HERE');
   define('SUPABASE_SERVICE_KEY', 'YOUR_SERVICE_ROLE_KEY_HERE');

3. Replace with your actual values from Step 2
4. Save the file

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "PHP is not recognized"
Solution: Make sure PHP is installed and added to PATH (see Step 1)

Problem: "Call to undefined function curl_init"
Solution: 
  - Find php.ini file (in C:\php or C:\xampp\php)
  - Open in Notepad
  - Find line: ;extension=curl
  - Remove semicolon: extension=curl
  - Save and restart server

Problem: "Could not connect to Supabase"
Solution:
  - Check config.php has correct credentials
  - Verify Supabase project is active
  - Make sure schema.sql was executed successfully

Problem: "Session could not be started"
Solution:
  - Check that C:\Windows\Temp exists and is writable
  - Or add to config.php: ini_set('session.save_path', sys_get_temp_dir());

Problem: Page shows PHP code instead of running
Solution:
  - Make sure Apache is running (XAMPP)
  - Or use START_SERVER.bat (PHP built-in)
  - Files must have .php extension
