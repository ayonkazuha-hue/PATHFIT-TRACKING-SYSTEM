2. Run the installer

   - Accept all defaults
   - Install to: C:\laragon

3. Launch Laragon (it will auto-start)

═══════════════════════════════════════════════════════════════════════════════

1. Copy this entire folder:
   C:\Users\NBSC\Documents\PATHFIT TRACKING SYSTEM\

2. Paste it into:
   C:\laragon\www\

3. Rename the folder to just: pathfit
   (Remove "PATHFIT TRACKING SYSTEM", keep just "pathfit")

4. In Laragon, click "Start All"

5. Right-click Laragon tray icon → www → pathfit

6. Browser opens automatically at: http://pathfit.test/login.php
